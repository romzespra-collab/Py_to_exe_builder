История версий py_to_exe_builder
================================
Последняя версия — 0.9.9.
Отсюда программа берёт «Что нового» при обновлении с GitHub (разделы «X.Y.Z:»).

0.9.9:
  Порядок: журнал — последние 10 версий (здесь и в шапке программы); одно
  описание README.md (README.txt убран, в папке программы стирается разово
  при запуске из исходников); модуль обновления gh_update 1.4.3 (замена
  файла с повтором, если его на миг занял антивирус; маски в разовой
  чистке).

0.9.8:
  Обновление с GitHub (gh_update 1.4.2): свои папки tools/ и modules/
  никогда не чистятся; копия из git (.git рядом) старый код не чистит;
  занятый список файлов — не повод чистить; исчерпан лимит запросов GitHub
  — понятное сообщение, а не «токен не видит репозиторий»; вышла новая
  версия, пока окно было открыто, — понятное сообщение вместо 404; окно во
  время простой проверки версии закрывается (держит только
  скачивание/установка).

0.9.7:
  Python 3.12+: код очищен автоправкой ruff (кодировка в шапке), поведение не менялось.

0.9.6:
  Python 3.12+: убрана цель сборки «Windows 7» в «Целевая ОС» (portable Python 3.8,
  пины PySide6==6.1.3 / numpy<1.25, get-pip для 3.8/3.9, проверка Win7+ARM64,
  отключение ffmpeg для Win7, гибридная Win7-сборка с yt-dlp_win7.exe).
  Остались: текущий Python, Windows 10+ (3.12), Windows 11 (3.13), свой
  Python. PySide6 ≥ 6.10.1, gh_update 1.4.1 (код модуля очищен автоправкой).

0.9.5:
  Обновление — только Python: убрано обновление собранного exe (gh_update
  1.4.0), GitHub больше не собирает exe.

0.9.4:
  Обновление с GitHub: общий модуль gh_update 1.3.3 (обрыв ответа GitHub —
  понятная ошибка, при сбое замены не остаётся *.upd, свои файлы пользователя
  не стираются, та же версия после установки не предлагается снова).

0.9.3:
  Обновление с GitHub (gh_update 1.2.0): старый код, которого нет в новой
  версии, стирается; резервной папки backup больше нет; настройки не трогает.

0.9.2:
  Обновление: модуль gh_update 1.1.3 — в облаке анимации значок GitHub
  над надписью; архив докачивается при обрыве.

0.9.1:
  Обновление модуля gh_update 1.1.1: «Что нового» из журнала проекта
  (CHANGELOG.txt); инструкция «Как получить токен» показывает
  настоящий файл с номером версии; кнопка автопроверки — в цветах темы.

0.9.0:
  Обновление с GitHub: меню ⋯ → «🔄 Обновление с GitHub…». Токен GitHub
  «только чтение» (кнопка «?» — пошаговая инструкция с картинками), ветка,
  «Проверять автоматически» (через 30 с после запуска и дальше каждые
  1 ч … неделю), «Проверить сейчас», «Обновить до X.Y.Z», анимация
  скачивания, «Что нового», перезапуск. Есть новая версия — кнопка
  «⬆ X.Y.Z» в шапке и пометка в меню. Настройки обновления хранятся
  вместе с остальными; «Сбросить настройки» токен не трогает. Заменённые
  файлы — в backup/v<старая версия>/.

Более ранние версии — в истории git.
