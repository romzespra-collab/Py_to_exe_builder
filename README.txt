py_to_exe_builder  v0.8.3
═════════════════════════

Py To EXE Builder — графический сборщик Python-проектов в Windows EXE
(PyInstaller + PySide6/Qt6). Автор: RomzesPRA-2026.


ЧТО ДЕЛАЕТ
──────────
• Перетаскиваешь главный .py/.pyw (или папку проекта) в окно и жмёшь
  «🚀 Сделать EXE» — остальное сборщик делает сам.
• Анализирует импорты проекта: всего / сторонние / неизвестные (видно
  в плитках шапки), пишет requirements_detected.txt и отчёт.
• Универсальный EXE: VC++ Runtime внутри + crash-logger (<имя>_crash.log).
• Авто-оптимизация: лишние модули Qt исключаются (EXE в 5–10 раз меньше),
  UPX-сжатие, авто-bundle ffmpeg для yt-dlp / moviepy / pydub.
• Целевая ОС: текущий Python или авто-скачиваемый portable Python
  под Windows 7 / 10 / 11 (x64 / x86 / ARM64) — в систему ничего не ставится.
• 267 встроенных иконок (8 стилей) или своя .ico.
• Тёмная/светлая тема (☀/☾), своя рамка окна; все поля и опции
  запоминаются сами.


СТРУКТУРА
─────────
py_to_exe_builder.pyw   программа целиком (двойной клик — запуск без консоли)
py_to_exe_builder.spec  настройки PyInstaller: один файл, без консоли, без UPX
build_exe.bat           сборка EXE одним кликом (с самопроверкой)
requirements.txt        нужные библиотеки (PySide6>=6.5)
README.txt              этот файл
README.md               кратко для GitHub

Рядом с собираемым проектом сборщик создаёт папки:
EXE_Output\            готовый EXE, requirements_detected.txt, отчёт анализа
_py_to_exe_builder\    рабочая папка сборки (build/spec, UPX, кэш)


ЗАПУСК
──────
1. Нужен Python 3.10+ (python.org, галка «Add to PATH»).
2. Двойной клик по py_to_exe_builder.pyw.
   Библиотеки (PySide6) поставятся сами при первом запуске — откроется
   окно с ходом установки pip. Если не получится — появится окно
   с командой для ручной установки.

Самопроверка (без окна):  python py_to_exe_builder.pyw --selftest
→ итог в консоли и в selftest.txt рядом с программой, код возврата 0/1.


СБОРКА В EXE
────────────
Двойной клик по build_exe.bat:
  [1/4] проверка Python
  [2/4] pip install -r requirements.txt + PyInstaller
  [3/4] PyInstaller по py_to_exe_builder.spec
  [4/4] dist\py_to_exe_builder.exe --selftest (ошибка → сборка остановится)
Готовый файл: dist\py_to_exe_builder.exe
